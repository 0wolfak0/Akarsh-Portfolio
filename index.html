📜 Preprint Zenodo

Adaptive Deceptive Response Framework for Prompt Injection Attacks on Large Language Models

Shetty, Akarsh J

This paper presents a self-hosted security middleware that sits between client applications and a locally hosted LLaMA-3 model, performing multi-layer threat detection. The pipeline combines leetspeak-aware keyword matching, Shannon-entropy based obfuscation detection, and LLM-based semantic classification, fused into a weighted risk score routing requests into SAFE, MONITOR, or DECEPTION modes. The DECEPTION mode functions as a natural-language honeypot, engaging attackers with dynamically generated fake data while logging behavior.

Prompt Injection LLM Security Honeypot Deception Response Semantic Classification
